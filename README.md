# 3-body-problem-python-sim
a simple python code that we made at Adiss Ababa Univeristy  statistical and computational physics lab to simulate the potential orbits of the sun earth and mars with variable time and using accurate and precise formulas and data taking in account of the 3 body problem and follows all rules of newton
it can be edited and can be used to simulate of other 3 objects (need to fill out the constants and variables with the data of the other objects).
it uses matplot lib and numpy(pip install matplotlib numpy)
presented at aau lecture room LH-06 at September/5/2026
